# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理
2. 编译
3. 汇编
4. 链接

建议控制在 300～500 字，不需要展开复杂细节。  

## 01预处理‌
这是编译前的文本整理步骤，只处理所有以#开头的指令：把#include引用的头文件内容完整复制到当前代码里，把#define定义的宏做纯文本替换，根据#ifdef、#endif这类条件编译指令保留或删除对应代码，同时删掉所有注释和多余空行。处理完会生成一份内容更完整、没有任何预处理指令的C代码文件。  
## 02编译‌
这是整个流程的核心转换环节，编译器会对预处理后的C代码做全面检查：先拆分出代码里的关键字、标识符等元素，再校验语法是否符合规则、变量类型是否匹配，做完可选的代码优化后，最终把高级C语言转换成和CPU架构对应的汇编代码文件。我们平时遇到的“少分号”“类型不匹配”这类报错，大多都出现在这个阶段。
## 03汇编‌
汇编器会把上一步生成的汇编助记符，逐条翻译成计算机能直接识别的二进制机器指令，生成后缀为.o的目标文件。这个文件里已经是纯二进制代码，但它还不能直接运行，里面很多函数调用的地址都还是空白的待填充状态。
## 04‌链接‌
链接器会把所有零散的目标文件、用到的系统库文件拼接整合到一起，找到代码里调用的printf这类不在你自己文件里的函数，从系统库中匹配到它们的真实地址，把所有空白的地址位全部填充对齐，最终生成一个完整、可以直接在系统上运行的可执行程序。
